Gleiche mit GitHub ab …

Die Seite liest bei jedem Öffnen die Repo-Liste von GitHub. Neue Repos und neue Unterordner mit einer index.html erscheinen von selbst, gelöschte verschwinden.

Mit „Verschieben“ an jeder Karte änderst du die Kategorie. Die Zuordnung wird als Datei zuordnung.json im Repo gespeichert und gilt für alle, die die Seite öffnen. Speichern können nur Geräte mit eingerichtetem Zugang.

Neue Einträge werden nach Stichwörtern einsortiert und tragen die Marke „neu“, bis sie einen festen Titel und eine Kategorie bekommen.
